# Fluxos principais

## Cadastro e onboarding

Cadastro → confirmação opcional em até 24h → dados do estabelecimento → segmento → sugestões da Biblioteca Mestre → seleção manual → Dashboard.

## Biblioteca

Biblioteca → aba/filtro → detalhe → Copiar → revisão → salvar cópia privada → editar/personalizar.

## Receita

Meu Acervo → Nova receita → campos e ingredientes → validação → salvar → favoritar/adicionar ao cardápio.

## Produto

Meu Acervo → Novo produto → dados comerciais opcionais → validação → salvar.

## Publicação

Meu Cardápio → escolher cardápio ou catálogo → selecionar itens → ordenar → definir disponibilidade/preço → publicar → gerar link/QR → compartilhar.

## Exclusão

Excluir → informar lixeira de 30 dias → confirmar → soft delete → restaurar ou excluir definitivamente.

## Assinatura

Plano → escolher mensal/anual → Mercado Pago → retorno/webhook → atualizar entitlements → exibir estado de cobrança.

## Público

Link/QR → confirmação de maioridade quando necessário → consulta → contato pelo WhatsApp.
